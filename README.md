# java-calculator-precourse

### 구현할 기능 목록
- [ ] 기능
  - [ ] 커스텀 구분자 지정
    - `//`와 `\n` 사이에 위치하는 문자
  - [ ] 문자열을 구분자로 구분
    - `,` 또는 `:` 기본 구분자를 기준으로 나누기
    - 커스텀 구분자가 있다면 해당 구분자로 나누기
    - 구분자나 숫자 형식이 잘못된 경우 `IllegalArgumentException` 발생 후 종료
  - [ ] 구분된 문자열 합하기
    - 모든 문자는 양수만 허용
    - 빈 문자열 입력 시 결과 → `0`

---

- [ ] 출력
  - [ ] 시작 문구 출력
    - `덧셈할 문자열을 입력해 주세요.`
  - [ ] 사용자 입력(문자열)
    - 예: `1,2:3`
  - [ ] 결과 문구 출력
    - 예: `결과 : 6`
